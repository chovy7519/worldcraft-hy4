# 验收场景与全链路验证记录（v1.2.0 可编辑几何版）

环境：Windows 10 / Node 22.22.2 / Chrome（WebGL 2.0，SwiftShader 软件渲染验证通过）/ Vite 5 / R3F 8。
默认种子：`20261106`。默认场地：`400 × 400 m`，`cellSize = 8 m` → 50×50 网格。

---

## A. 手动复现

```bash
cd worldcraft && npm install && npm run dev
# 浏览器打开 http://127.0.0.1:5190
```

| 步 | 操作 | 期望 |
| --- | --- | --- |
| 1 | 点击命令面板 `▶ 运行验收演示` | 自动跑完全流程；或按 2–8 手动逐步验证 |
| 2 | 输入验收语句 1，点「解析」 | 命令预览出现 `scene.create(400,400)`、`height.profile=centerHigh`、`height.max=180`、`height.base=16`、`openSpace.enabled=true`、`material.palette=future` |
| 3 | 点「校验并执行」 | 视口生成中心高、外围低、带中央圆形绿地的城市；HUD 显示 `空间校验 PASS` |
| 4 | 输入验收语句 2，解析并执行 | 命令预览为单条 `density.adjust east relative -0.3` |
| 5 | 打开 PCG Inspector →「规则变化」 | 显示 `density.zoneMultipliers.east 1 → 0.7`，作用域「东侧」，来源 `nl` |
| 6 | 打开「生成管线」 | 显示 7 层 DAG、各阶段依赖与产出、空间无重叠校验 PASS、扩展点契约 |
| 7 | 打开「场景统计」 | 东侧建筑数下降，其他四个分区统计值不变；可见道路/地块/公园/树木/原型统计 |
| 8 | 依次点「撤销」「重做」「保存」→改种子→「加载」 | 撤销后指纹回到上一步；保存/加载后 HUD 指纹与存档一致，状态栏提示「一致性校验通过」 |

**无 AI 路径**：关闭「AI 接口设置」中的启用开关（默认关闭）。上述全部步骤使用本地规则解析器，不发起任何网络请求。管线参数可直接在 Inspector 调整，或点「管线：…」结构化命令预设后「校验并执行」。

## D. 未覆盖 / 明确不做

- 未实现自由节点图编辑、Blender Geometry Nodes、Unreal PCG 对接（后续阶段）。
- 未实现任意类型三维世界、真实地形起伏、曲面道路、任意多边形挤出的建筑体量（建筑足迹用旋转内接矩形族表达）。
- 落在道路段上但不在图节点处的顶点移动会被明确拒绝；连续两次 `parcel.merge` 在长/短边端点不匹配时可能被跳过并记入 `skippedEdits`（凹形地块推荐用「删两条相邻路段」路径）。
- E1 水系 / E2 地形要素目前只生成占位几何，未实现水系拓扑连通、坡度与高程回填；接口契约已声明。
- 未训练任何三维生成模型，未调用一次性 Text-to-3D 服务。
- LLM 为可选增强，未配置时不影响任何验收项；本记录中的浏览器实测全程未配置 API Key。
- 浏览器直连 LLM 的密钥仅存 localStorage；生产部署前应改后端代理。
