# WorldCraft 视觉体系规范 v1.0 — 制图语言（Drawing Language）

> **结论先行**：用户提供的 5 张参考图不是「一套配色」，而是**一套建筑制图的表达语法**。当前 UI 的问题不在颜色偏暗，而在它用的是「软件仪表盘」语言（卡片、圆角、阴影、发光、控件堆叠），与参考图的「图纸」语言（编号、引线、图例、比例尺、线稿、图案填充）不同构。因此改造目标不是把深色换成浅色，而是把**信息组织方式**从「控件」翻译成「注记」。

本文件是 `src/styles.css` 与三维场景配色的唯一判断依据。参考图仅作风格来源，不作为素材使用。

### 共性（5/5 命中）

1. **平涂，不渐变、不发光、不金属高光、不玻璃拟态。**
2. **线先于面**：1px 级细线定义形状，色块在线内填充；没有 box-shadow 制造层级。
3. **图案即材质**：斜线、点阵、网格、瓦片线承担"区分"职能，而不是靠明暗或模糊。
4. **低饱和大面积 + 极少量高饱和强调**：荧光黄 / 朱红 / 青蓝只在关键处出现，面积 < 5%。
5. **正投影或等距**，无透视消失点；图面边界清晰，四周留白。
6. **信息靠注记而非控件**：编号、引线、图例、比例尺、指北针、页码构成层级。

### 差异（不可混为一谈）

- 图 1 是**深底白线**的"海图"，图 2–5 是**浅底墨线**的"图纸"。二者是同一语法下的两套明暗主题，不应只取其一。
- 图 2 是饱和手绘（绿量 > 70%），图 3/4 是低饱和淡彩（留白 > 40%）。软件界面应取**图 3/4 的克制**，不能取图 2 的饱和度——长时间注视会疲劳。

## 3. 关键判断（不照单全收）

**判断一：参考图是「成果图面」，不是「操作界面」，直接照搬会损失可用性。**
图 3/4 的背景建筑刻意褪色到几乎不可见、正文小到 8px、无焦点态——这在汇报图上成立，在编辑器里会导致拾取困难、状态不可辨。因此采用**双层策略**：

- **外壳（TopBar / Hierarchy / Inspector / CommandPanel）**：借用制图语法，但保留功能性对比（数据等宽、状态实底色块、选中高反差）。
- **视口（Canvas）**：完整采用淡彩制图配色，作为"图面"存在。
- 两者之间用 1px 墨线分隔，不使用阴影。

**判断二：不做插画化贴图。**
不在 UI 里塞手绘树、小人或纹理图片。图案填充只用 CSS `repeating-linear-gradient` 生成 45° 斜线与方格，保持矢量、可缩放、零资源依赖。参考图的"手绘感"来自图面内容，不应污染控件。

**判断三：视觉层与数据层严格隔离，不触碰已验收的确定性。**
`core/pipeline/stages.ts` 的 `PALETTES` 中 `b.color` 计入场景指纹（`fingerprintOf` 的 `buildings[]`）。改它会让 README / ACCEPTANCE 中全部指纹（`381A0250`、`BE29C1BA` 等）和验收数据失效。因此：

- `core/` 中仅调整两个**纯展示常量** `ZONE_COLORS` / `LAND_USE_COLORS`（已验证：只被 `components/` 引用，测试零引用，不进指纹）；
- 材质视图的淡彩化在 `CityScene` 渲染层用 `draftColor()` 做 HSL 重映射，属于呈现变换；
- **不修改 `PALETTES`、不修改任何几何或规则参数**。相同 `SceneDocument` → 相同指纹这一不变量保持不变。

**判断四：提供双主题而非单主题。**
浅色「图纸」对应图 2/3/4/5，深色「海图」对应图 1。图 1 的白线注记 + 荧光黄 + 虚线菱形网格是最完整的注记范式，丢掉等于丢掉 1/5 的参考信息。主题存 `localStorage`，不进 `SceneDocument`，不影响指纹。

## 7. 不变量与验收口径

改造不得破坏以下项目既有约束：

1. 相同 `SceneDocument` → 相同场景指纹；README 中 `381A0250` / `BE29C1BA` / `B2FBF375` 等验收值不变。
2. `npm run typecheck`、`npm run build`、`npm test`（12 文件 / 93 用例）全绿。
3. 所有既有 `className` 保持不变，样式改造不改动 DOM 结构（主题切换按钮除外）。
4. 全部视觉资源为 CSS / WebGL 生成，不引入图片、字体文件或第三方 UI 库。
5. 天地图等外部底图规则不受影响（本模块为纯本地三维场景）。

视觉验收对照：`docs/styleboard.html` 提供双主题组件级预览；实际工作台通过顶栏「图纸 / 海图」切换。
