三渲二 · 日常街区

阳光充足的普通街区，像一张可以走进去的动画背景画。轮廓优先、色块优先、生活痕迹优先——不是未来城市，不是效果图。

适用范围 三维场景内容层 UI 主题 保持制图语言，不混改 固定时间 晴日上午 10:00 统一模数 开间 3.2 m / 层高 3.0 m
01

色彩 · 高明度 / 低饱和 / 色相分工

70% 基底 · 20% 结构 · 10% 点缀　｜　饱和度 ≤ 45%

阴影不是变黑，而是基色向冷蓝紫 #8FA6BE 偏移约 22%，保持彩度与空气感。点缀色只允许出现在招牌、门头、标识等「生活信息」上，建筑本体不用高饱和。

光影 · 固定时间 / 三值阶梯 / 硬边投影

主光 225° · 仰角 48° · N·L 量化

三值 toon ramp

立面只允许三个明度阶，过渡带 ≤ 0.02，不出现连续渐变

N·L > 0.650.28–0.65< 0.28

轮廓 · 稳定压倒一切

深暖灰而非纯黑；几何挤出（inverted hull），不用边缘检测

外轮廓 #4A4640 / 1.5 px内轮廓 #6B655C / 0.8 px远景仅降对比，不消失
03

五类建筑 · 立面示意与细节密度

同一色板 / 同一描边 / 同一 3.2 m 开间模数

下方五张立面全部用目标风格绘制：平涂色块 + 统一深暖灰描边。差异只体现在 L4 装饰层与内轮廓数量，基底与窗格逻辑保持一致——这是「可辨识」与「风格统一」同时成立的关键。

住宅中 · 8–14 件
residential → slab / incubator
  • 4–6 层板楼，坡屋顶陶瓦
  • 模数重复 + 每层 1–2 处个体变异
  • 阳台横带 / 晾衣 / 花盆 / 门帘
  • 无商业招牌，仅门牌与信箱
商业高 · 14–22 件
commercial → podium / incubator
  • 1–3 层沿街小体量，首层通透大开口
  • 逐店不同，招牌朝路、每开间 1 块
  • 遮阳棚 / 暖帘 / 立牌 / 贩卖机 / 陈列
  • 点缀色只在此类集中出现
办公低 · 4–6 件
office / research → slab / research
  • 5–8 层规整矩形，水平带窗
  • 严格重复，不允许个体变异
  • 仅入口雨棚与 1 处铭牌
  • 不加窗框描边，保持安静
交通中低 · 6–8 件
当前无 LandUse → 建议设施实例层
  • 低矮横向体量 + 大挑檐 / 站棚
  • 全线统一制式，标识优先
  • 站牌 / 候车亭 / 信号灯 / 车架 / 邮筒
  • 蓝绿 #4E7E96 为唯一功能标识色
休闲中低 · 5–8 件
park / plaza → 建议公园设施实例层
  • 1–2 层坡顶小屋 / 亭 / 廊
  • 构件少、材质温润，允许不对称
  • 木牌手写感，仅 1 处/亭
  • 长椅 / 饮水台 / 垃圾桶 / 树池

05

生活化氛围 · 成组而非撒点

每 100 m 街道 12–18 件 · 至少 1 处「不整齐」· 必须有留白段
住宅沿街 / 每 2–3 开间一组
晾衣阳台花盆空调外机自行车门帘信箱
商业沿街 / 每店一组，招牌必须朝路
门头招牌遮阳棚陈列架立牌自动贩卖机暖帘
办公沿街 / 每栋 1–2 处，克制
入口雨棚铭牌行道树池旗杆
交通节点 / 每路口或站台一组
站牌候车亭信号灯自行车架导向标识邮筒
休闲空间 / 每 200 m² 一组
长椅饮水台亭子垃圾桶树池儿童设施
关键：连续铺满 = 主题乐园。生活物件必须成组、有归属、有叙事，并留出「空」的街道段落；每 100 m 至少 1 件不整齐（歪的花盆、半拉的帘子）。所有「不整齐」必须由 sample(seed, 盐, 稳定序号) 决定，禁止 Math.random()。
06

需要避免的表现倾向

逐条对照，左栏任一出现即不通过
应避免
  • 赛博朋克霓虹、冷蓝玻璃幕墙、165 m 塔楼（就是当前默认场景）
  • 写实 PBR、脏污做旧、HDR 高对比、连续光照渐变
  • 纯黑粗描边、法线/深度边缘检测（视角一动就抖）
  • 全城高饱和、每栋一个颜色，糖果城效果
  • 所有建筑同样细节密度，功能不可辨识
  • 生活物件均匀撒点，像贴图填充、没有叙事
  • 空旷大广场、超尺度纪念性空间、无人尺度
  • 动态昼夜 / 天气 / 随机色温
  • 每栋独立贴图与材质、法线贴图堆细节
  • 过度 Q 版、夸张头身比、一切倒圆角
  • 玻璃反光、镜面水面、透明贴图叶片
  • 顺手改编辑器 UI 配色
替代方向
  • 降层高至 12–24 m、暖色板、取消中心高剖面、住宅/商业主导
  • toon 三值 ramp + 固定主光 + 有限 AO（≤ 0.25）
  • 深暖灰 #4A4640、几何挤出、屏幕空间恒定 1.5 px
  • 70/20/10 明度分布，点缀色只给生活信息，饱和度 ≤ 45%
  • 按密度梯度：办公最低、商业最高，差异只在 L4
  • 成组、有归属、留白段、至少一处不整齐
  • 14–18 m 小开间、口袋绿地、步行尺度
  • 固定「晴日上午 10:00」；变化另做预设并重新校准 ramp
  • 一张共享 atlas + 模块化 UV + 实例色
  • 正常人体比例、简化面部、构件精细但形体克制
  • 块状单色高光、水面平涂、三色阶团块树冠
  • 场景主题与 UI 主题分开管理，不动 SceneDocument
07

落地顺序 · 先验证方向，再谈工程

P0 不动几何 · P3 才是长期投入

可快速验证（P0）

换色板 + toon 三值材质 + 固定主光 + 轮廓 + defaultRules 尺度调整

  • 不改 SceneDocument、不改 PCG、不动 168 个用例的几何契约
  • 改动点：stages.ts::PALETTES、CityScene.tsx::THEME / draftColor()、新增 ToonMaterial、schema.ts::defaultRules()
  • 产出：一张可对比的效果截图，先确认方向对不对

需要长期工程（P1–P3）

共享窗格 atlas → 功能细节层 → 模块化构件库 / 分块 LOD

  • draw call 从 7 类涨到 20+；toon shader 必须保留 instanceColor
  • 描边需第二组同矩阵实例，2 km 场景实例数翻倍
  • 2 km 生成实测 6.6 s，构件必须走「原型 + 实例矩阵」
  • P0 未被确认前，不要启动 P3
